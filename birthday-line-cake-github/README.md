# Birthday Line Cake

这是独立的生日网站，不需要覆盖作品集仓库。

发布：
1. GitHub 新建 Public 仓库 birthday-line-cake。
2. 解压此文件包。仓库 Add file → Upload files，上传解压后的全部文件和 photos 文件夹；index.html 必须在仓库根目录。
3. Commit changes。
4. Settings → Pages → Source 选择 Deploy from a branch，Branch 选择 main 和 / (root)，保存。
5. 等待 GitHub Pages 部署成功；用 Pages 页面显示的 Visit site 链接访问。

网站包括生日祝福及四张相册照片，发布后访客可查看。
